В репозитории три задания первой лабораторной. Каждое лежит в своей папке. Для запуска нужен Python 3; открыть файлы можно в VS Code, PyCharm или другом редакторе Python. Программы запускаются в терминале и сами запрашивают данные.

## 1. Формула Герона

По трём сторонам программа вычисляет площадь треугольника. Если такой треугольник не существует, выводит сообщение об этом.

Файл: [`heron.py`](01%20—%20Формула%20Герона/heron.py). Из папки проекта запустить `python3 heron.py`, затем ввести стороны `a`, `b` и `c`. Площадь выводится с двумя знаками после запятой.

Проверка: [стороны 3, 4, 5](01%20—%20Формула%20Герона/screenshots/test-1.png), [дробные стороны](01%20—%20Формула%20Герона/screenshots/test-2.png), [невозможный треугольник](01%20—%20Формула%20Герона/screenshots/test-3.png).

## 2. Конвертер расстояний

Программа переводит расстояние между километрами (`km`), метрами (`m`), сантиметрами (`cm`), миллиметрами (`mm`), милями (`mi`) и ярдами (`yd`).

Файл: [`converter.py`](02%20—%20Конвертер%20расстояний/converter.py). Из папки проекта запустить `python3 converter.py`, затем ввести исходную единицу, целевую единицу и число. Результат выводится с шестью знаками после запятой.

Проверка: [1 km → m](02%20—%20Конвертер%20расстояний/screenshots/test-1.png), [1500 m → km](02%20—%20Конвертер%20расстояний/screenshots/test-2.png), [1 mi → yd](02%20—%20Конвертер%20расстояний/screenshots/test-3.png).

## 3. Високосный год

Программа определяет, является ли введённый год високосным. Год, кратный 100, считается високосным только при делении на 400.

Файл: [`leap_year.py`](03%20—%20Високосный%20год/leap_year.py). Из папки проекта запустить `python3 leap_year.py` и ввести год.

Проверка: [2024](03%20—%20Високосный%20год/screenshots/test-1.png), [1900](03%20—%20Високосный%20год/screenshots/test-2.png), [2000](03%20—%20Високосный%20год/screenshots/test-3.png).
